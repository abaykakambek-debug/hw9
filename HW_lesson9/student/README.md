# AI Product — Урок 9: тестирование и отладка

Учебный проект для Python 3.10+. Здесь **нет Telegram-токенов и реального сетевого API**: внимание на тестировании бизнес-логики, SQLite и парсера.

## Запуск

python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS:
# source .venv/bin/activate
python -m pip install -e ".[test]"
python -m pytest -v

Если PowerShell блокирует активацию, используйте `.venv\Scripts\python.exe -m pip install -e ".[test]"` и `.venv\Scripts\python.exe -m pytest -q`.

## Задания (90 минут)

1. **20 мин — pytest:** запустите тесты. Добавьте по 2 теста для `Hero`, `Product`, `Database`. Проверьте крайние значения: 0, отрицательные числа, пустые строки.
2. **20 мин — Bug Bounty:** обменяйтесь ссылками на GitHub-репозитории в парах. Воспроизведите минимум одну ошибку, создайте Issue с шагами, ожидаемым и фактическим результатом. Не публикуйте токены.
3. **20 мин — Fix:** сначала добавьте падающий тест, затем исправьте баг, запустите весь набор тестов, сделайте коммит `Fixes #N`. Issue автоматически закрывается после попадания такого коммита в default branch; иначе закройте вручную после проверки.

## Подсказки для тестирования без сети

`parse_products(lambda: {"products": [{"name": "Book", "price": 10}]})` — фейковый ответ.

Проверьте пустой список, отсутствие ключа `products`, отрицательную цену, исключение от источника. Для БД используйте `Database(":memory:")` или `tmp_path`.

## ИИ как помощник

Попросите ChatGPT предложить 10 тест-кейсов для `Hero`, `Product`, `Database` и 5 фейковых ответов для парсера. Выберите полезные, объясните 2 отклонённых варианта. Не передавайте токены и персональные данные.

## Критерии сдачи

- Не менее 6 осмысленных тестов; все проходят после исправлений.
- Хотя бы один воспроизводимый Issue и связанный исправляющий коммит.
- Тесты работают без интернета и не меняют рабочую БД.
- Краткий отчёт о том, что пропустил ИИ.
